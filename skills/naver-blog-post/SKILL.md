# 네이버 블로그 매장 글 작성

검색하는 사람은 글이 아니라 답을 찾는다. 검색어에 대한 답을 사진과 함께 준다.

## 절차

1. **검색어 정하기.** "지역명 + 업종/메뉴" 조합으로 실제 검색될 키워드를 1개 정한다(예: 청량리 술집, 회기역 파스타). 글 1개에 주력 키워드 1개. 완료 기준: 제목에 그 키워드가 자연스럽게 들어간다.
2. **본문 구조.** 1,000자 이상. 순서: 방문 상황(왜 갔나) → 위치와 찾아가는 길 → 메뉴와 가격(사진 자리 표시) → 맛/서비스 구체 묘사 → 총평과 추천 대상. 사진 자리 8~10곳을 [사진: 설명] 형식으로 표시해 사장님이 채우게 한다.
3. **신뢰 요소.** 실제 가격, 영업시간, 지도(플레이스 링크) 자리를 넣는다. 확인 안 된 정보는 [확인 필요]로 표시한다.
4. **태그.** 10개: 지역명 변형 3~4개 + 메뉴명 3~4개 + 상황 키워드 2~3개(회식, 데이트 등).
5. **완료 기준:** 제목만 보고 검색 의도에 답하는 글임을 알 수 있는가, 1,000자 이상인가, 사진 자리 8곳 이상인가. 하나라도 아니면 보완한다.

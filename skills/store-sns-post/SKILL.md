# 매장 SNS 게시물 작성

광고처럼 보이는 글은 넘겨진다. 손님의 문제에서 시작해 4구조로 쓴다.

## 절차

1. **매장 사실 확인.** 상호, 위치, 메뉴 이름, 가격, 영업시간을 사장님에게 받은 자료에서만 가져온다. 자료에 없는 정보는 지어내지 말고 물어본다. 완료 기준: 글에 들어갈 모든 사실에 출처가 있다.
2. **4구조로 초안 작성.**
   - 훅(1줄): 손님이 겪는 순간을 정확히 찌른다. (예: "퇴근길에 밥하기 싫은 날")
   - 해결(1~2줄): 메뉴나 서비스가 그 순간을 어떻게 해결하는지.
   - 증거(1~2줄): 구체 숫자나 실물. 가격, 양, 원산지, 후기 수. 과장 표현(최고, 유일, 무조건)은 쓰지 않는다.
   - 행동유도(1줄): 딱 1개만. 예약, 방문, 저장 중 하나.
3. **채널별 변형.** 인스타그램은 해시태그 5~10개(지역명+메뉴명 조합 필수), 스레드는 해시태그 없이 대화체, 페이스북은 문장을 조금 더 길게.
4. **자가 점검 후 제출.** 완료 기준: 훅이 매장 자랑이 아니라 손님 상황으로 시작하는가, CTA가 1개인가, 모든 숫자에 출처가 있는가. 하나라도 아니면 다시 쓴다.

## 금지

- 확인 안 된 가격이나 영업시간을 쓰는 것
- 다른 매장 비방
- 같은 글을 여러 채널에 복사 붙여넣기 (채널별 변형 없이)

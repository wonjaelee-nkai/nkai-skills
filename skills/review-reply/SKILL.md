# 리뷰 답글 작성

답글은 리뷰 작성자보다 그 답글을 읽는 미래의 손님을 위한 것이다.

## 절차

1. **리뷰 분류.** 별점과 내용으로 셋 중 하나로 나눈다: 호평 / 개선 지적 / 악성(사실무근, 욕설).
2. **유형별 작성.**
   - 호평: 감사 + 리뷰에 나온 구체 포인트 1개를 되짚기 + 재방문 유도 1줄. 복사 붙여넣기 티가 나는 상투구("소중한 리뷰 감사합니다")로 시작하지 않는다.
   - 개선 지적: 변명 없이 인정 + 무엇을 바꿀지 구체적으로 + 다시 기회를 달라는 요청. 지적받은 사실을 부정하지 않는다.
   - 악성: 감정 대응 금지. 사실관계만 차분히 기록하고(날짜, 주문 내역 확인 요청), 필요하면 플랫폼 신고 절차를 사장님에게 안내한다. 법적 표현(명예훼손 등)은 답글에 쓰지 않는다.
3. **톤 통일.** 매장의 말투(존댓말 정도, 이모지 사용 여부)를 기존 답글에서 파악해 맞춘다. 기존 답글이 없으면 사장님에게 1회 확인.
4. **완료 기준:** 답글이 미래 손님에게 "이 가게는 손님 말을 듣는구나"로 읽히는가. 아니면 다시 쓴다.
